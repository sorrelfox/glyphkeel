# Keyboard shortcuts

Glyphkeel can be used without a mouse. Press `?` (outside a text field) for the
shortcuts of the window and the view you are in, or open Preferences ›
**Keyboard shortcuts** to search them all. Those two lists come from the program
itself; this page lists the defaults. Changing the keys comes in a later version.

Shortcuts made of a single letter, such as N or T, work only when no text field
has the focus.

## Application

| Keys | Action |
|---|---|
| Ctrl+K | Search or run a command (the command palette) |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Ctrl+, | Preferences |
| Ctrl+Shift+L | Lock Glyphkeel ([Encryption and the app lock](encryption-and-lock.md)) |
| ? | Keyboard shortcuts |
| Ctrl+Q | Quit |

## Navigation

| Keys | Action |
|---|---|
| Ctrl+1 | Show the project as a board |
| Ctrl+2 | Show the project as a list |
| Ctrl+3 | Show the project as a Gantt chart |
| Ctrl+4 | Show the project's wiki |
| Ctrl+5 | Show the project as a calendar |
| Ctrl+F | Go to the filter query of the list, the calendar or the Gantt chart |
| Alt+Page Up | Previous period (calendar and Gantt chart) |
| Alt+Page Down | Next period (calendar and Gantt chart) |
| Alt+Home | Go to today (calendar and Gantt chart) |

## Tasks

| Keys | Action |
|---|---|
| Ctrl+N, N | New task |
| T | Start or stop the timer |
| Ctrl+Alt+Space | Quick add, from any program (change it in Preferences › Quick add) |

## Window

| Keys | Action |
|---|---|
| F9 | Show or hide the sidebar |
| F6 | Move focus to the next region |
| Shift+F6 | Move focus to the previous region |
| Ctrl+W | Close the window |

## The board

| Keys | Action |
|---|---|
| Arrow keys | Move between cards |
| Enter | Open the selected card |
| Space | Pick up the card; the arrow keys move it; Space drops it, Escape cancels |
| Alt+← / Alt+→ | Move the task to the column on the left or right |
| Alt+↑ / Alt+↓ | Move the task up or down |
| Alt+Shift+← / Alt+Shift+→ | Move the column left or right |
| Delete | Move the task to the trash |
| Menu key, Shift+F10 | Open the card's menu |

## The list

| Keys | Action |
|---|---|
| ↑ / ↓, Home, End | Move between rows |
| Enter | Open the task |
| Space | Select or clear the row |
| Ctrl+A | Select all |
| Escape | Clear the selection |
| F2 | Edit the title |
| Delete | Move the selected tasks to the trash |

## The calendar

| Keys | Action |
|---|---|
| Arrow keys | Move between days |
| Page Up / Page Down | Previous or next page |
| Enter | Go into the day's tasks |
| N | Add a task due that day |
| Alt+← / Alt+→ | Move the task by a day |
| Alt+↑ / Alt+↓ | Move the task by a week |

## The Gantt chart

| Keys | Action |
|---|---|
| ↑ / ↓ | Move between tasks |
| ← / → | Fold or unfold a parent task |
| Alt+← / Alt+→ | Move the bar by a day |
| Alt+Shift+← / Alt+Shift+→ | Make the bar a day shorter or longer |
| F2 | Edit the start date |
| Shift+F2 | Edit the due date |
| L | Link to another task: go to it and press Enter |
| Enter | Open the task |
| + / - | Zoom in or out |

## The project tree

| Keys | Action |
|---|---|
| → / ← | Open or close a folder or a project with sub-projects |
| Alt+↑ / Alt+↓ | Move a folder, or a top-level project within its folder, up or down |
| Shift+F10 | Open the menu of the project or folder |

## The wiki

| Keys | Action |
|---|---|
| E | Edit the page |
| Alt+↑ / Alt+↓ | Move the page up or down in the tree |
| Alt+→ | Move the page into the page above it |
| Alt+← | Move the page out of its parent |

## Editing text

| Keys | Action |
|---|---|
| Ctrl+Enter | Save a description or a page; send a comment |
| Esc | Cancel editing |
| `#` | Link a task |
| `[[` | Link a wiki page |
| `{{` | Insert a wiki macro (in wiki pages) |
| `/` | Insert a table, a code block, a diagram and other blocks |

## The command palette

| Keys | Action |
|---|---|
| ↑ / ↓ | Move |
| Enter | Open |
| Ctrl+Enter | Open a task in a new window |
| Tab | Show only tasks, projects or actions |
| Escape | Close |

## On Windows

The keys are the same. Shortcut hints say Ctrl, Alt and Shift, and show the
Windows logo key as Win.
